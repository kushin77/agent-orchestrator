# ignored). `make gate` runs each declared suite in ISOLATION
# (scripts/run-pytest-suites.sh) because the suites cannot share a single
# `pytest` invocation: sibling suites collide on `conftest.py` sys.path

#   * a declared suite that disappears   -> gate FAIL (coverage silently lost)
#   * a failing declared suite           -> gate FAIL
#   * a suite that is never declared     -> gate WARN (register it here)
#

# docs/QA-GATE.md "How to add a new suite").
