# scripts/gate-coverage-baseline.txt — accepted gate-coverage exceptions (#526),
# with provenance per issue #603.
#
# The ONLY way to shrink this list is to REMOVE an entry, by wiring the artifact
# into a gate file. `scripts/check-gate-coverage.sh` checks it in both
# directions:
#   * an artifact that is unwired and NOT listed here           -> NOT-OK, named;
#   * an entry whose artifact is wired NOW, is duplicated, no longer exists, or
#     is malformed                                              -> NOT-OK, named
#     as STALE (so an entry cannot sit here as a permanent excuse).
# A newly declared suite or a newly delivered `scripts/check-*.sh` is therefore
# NEVER grandfathered: it fails immediately, by name.
#
# Provenance (#603) — the rows below are provenanced so a lane cannot plant a
# row for its OWN new check:
#   * every row carries the issue that will retire it AND the 40-hex commit at
#     which the row was added (column 5); a row without both is malformed;
#   * EVERY LIVE row — a script row whose check no gate invokes, AND a suite row
#     whose suite no gate names as a pytest target — must name a tracker issue
#     that is still OPEN. A CLOSED tracker fails, naming the row and the issue;
#     so does a tracker ABSENT from the committed board snapshot, which is the
#     only board state a gate may read (offline, no network). A deferral to an
#     open lane is honest; a deferral to a closed one is a permanent excuse.
#     The rule covered `script` rows ONLY until #1497, and the `swept-only`
#     suite rows were exempt on the argument that their reason recorded a
#     permanent state rather than a deferred wiring — so 51 suite rows sat
#     against #524 (CLOSED 2026-09-14) and #502/#445/#447 (all CLOSED) while
#     this detector reported OK. The reason says WHY an artifact is unwired; it
#     does not make the row ownerless.
#   * a row for an artifact that did not exist at this file's OWN last-touched
#     commit, or at the 40-hex commit the row itself declares, fails as newly
#     delivered.
# NO `script` ROWS EXIST IN THIS FILE, and this paragraph used to claim three
# did — "live", deferred to #559 (RC-8, "the
# gate-wiring lane, OPEN") and retiring "the moment #559 wires those checks".
# Measured 2026-09-19 for #1497: `grep -cP '^script\t'` over this file = 0, and
# #559 closed 2026-09-14T20:32:15Z. A header describing rows that do not exist,
# deferred to an issue closed five days earlier, is the same defect as a row
# deferred to a closed issue, one level up: the DECLARATION, not the detector,
# had rotted. The paragraph is deleted rather than re-worded, so nothing here
# describes a row this file does not carry.
#
# Format — tab-separated, one artifact path per line (never a glob or a wildcard
# prefix: a glob would absorb a newly declared artifact under that prefix and
# quietly restore the opt-in hole this gate exists to close):
#
#   <kind>	<path>	<reason>	<tracker>	<sha>
#
#   kind     suite | script
#   reason   swept-only  suite: run only by the scripts/run-pytest-suites.sh
#                        manifest sweep; no gate file names it as a pytest target
#            uninvoked   script: delivered, invoked by no gate file
#   tracker  the issue that must remove this line; EVERY live row's issue must
#            be OPEN in the committed board snapshot, or the row is refused
#   sha      the 40-hex commit at which this line was added; for a row #1497
#            re-trackered, the commit that lane was cut from (a9f63bf4), because
#            a row cannot cite the commit that introduces it. The detector
#            requires only that the artifact exist at the cited commit.
