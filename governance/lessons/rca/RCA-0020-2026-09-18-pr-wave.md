## Impact

Across the ~90 PRs merged or closed on 2026-09-18, several defect classes
recurred across unrelated lanes without a ledger record: the squash-message
trailer being dropped on the way to master (11 recurrences, #1239/#1250);
two open PRs independently resolving one issue with nothing excluding the
other (#1097 vs #1115, #1131 vs #1106); a committed record carrying a
box-local path that had to be re-scoped twice (#1300 -> #1317 -> #1322); a
gate landing red on the very box that lands it, needing a dated ratchet
instead of an outright fail (#1327, #1335); a new control verb landing
without opinion/functions/bodies rows in the mapping table (#1287, #1315); a
mutant fixture that stopped anchoring once the literal it targeted changed
(#1285); a gate self-test that re-symlinked the interpreter and broke venv
resolution for a neighbour (#1353); and a semantic-merge rebase where a
reviewer pass, not a gate, is what caught a MEDIUM (#1120/#1111). None of
these classes had a ledger line, so each was re-discovered lane by lane
instead of being a known pattern with a named control.

## Detection

Read back from `gh pr list` titles/bodies for PRs merged or closed
`>=2026-09-18` (issue #1366's own evidence pull) — no live incident paged
anyone; each defect surfaced as a normal PR fixing the previous PR's gap
(#1250 fixing #1244/#1246; #1322 fixing #1317; #1315 fixing #1287) with no
record connecting the recurrences into one class.

## Root cause

The ledger only grows a record when someone stops to write one, and the two
cheapest of these classes (a duplicate PR against one issue, a semantic
merge nobody was asked to review) had no PR-body obligation at all — nothing
short of a human noticing would have caught them, so the gate could not
fail, which is the same root cause `scripts/check-pr-contract.sh`'s own
header already names (GR-12).

## Corrective actions

- `CA-0025` (issue #1366) — extend `scripts/check-pr-contract.sh` with two
  warn-only classification findings, `duplicate-pr-for-issue` and
  `review-required-for-semantic-merge`, each with a `--self-test` negative
  control, so the two cheapest recurring classes are provoked mechanically
  from now on.

## Lessons

Closed (each already proven by a landed master commit; recorded here so the
class is a pattern instead of nine separate one-off fixes):

- `LESSON-0016` — a committed record that carries a box-local path is wrong
  the moment it is written, not just when the box changes: scope the record
  to its venue at write time, never patch it twice after the fact (#1300,
  #1317, #1322).
- `LESSON-0017` — a gate that can land red on the very box that lands it
  needs a dated ratchet, not an outright fail, or the fix and the gate
  deadlock each other (#1327, #1335).
- `LESSON-0018` — a new control verb is not landed until the mapping table
  carries its opinion, functions and bodies rows; classifying the verb and
  wiring the gate are the same change (#1287, #1315).
- `LESSON-0019` — a mutant fixture anchors to a literal in the source; when
  that literal changes, the mutant must be re-anchored and the suite must
  assert `MUTANT-APPLIED`, not silently stop mutating (#1285).
- `LESSON-0020` — a gate's own self-test must not re-symlink the interpreter
  it runs under: that mutates shared venv resolution for every neighbour on
  the same box, not just the gate under test (#1353).
- `LESSON-0021` — a semantic-merge rebase (a merge commit that resolves real
  conflicts across a large diff) gets a reviewer pass by convention, not by
  gate; a PR-body obligation is cheaper than hoping the convention holds
  (#1120, #1111).

Closed by this same PR's own commit (`CA-0025`):

- `LESSON-0022` — two OPEN PRs whose trailer or branch resolve to the same
  issue is a race nothing excludes; `duplicate-pr-for-issue:<n>` names it,
  warn-only, in `scripts/check-pr-contract.sh`.
- `LESSON-0023` — a semantic merge over >200 changed lines needs a `##
  Review` section naming the reviewer's verdict, or the review that caught
  #1120/#1111's MEDIUM is a habit, not a control;
  `review-required-for-semantic-merge:<sha>` names it, warn-only, in the same
  gate.
